# Reflect — AI Daily Journal

A minimal AI-assisted journaling app for turning daily reflection into a structured habit.

## Features
- Morning planning
- Evening reflection
- AI-generated daily reflection
- Personal journal history
- Local journal storage

## Built with
- Python
- Streamlit
- OpenAI API
- Git / GitHub

## AI workflow
ChatGPT was used for product thinking, coding assistance, debugging and UX iteration. The OpenAI API powers the in-app reflection engine.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

Journal data is stored locally and excluded from version control.

## Product idea
Reflect focuses on one simple loop:

**Plan ? Act ? Reflect ? Notice patterns ? Improve**
